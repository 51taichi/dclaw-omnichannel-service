# 客服经验库检索

## 目标

根据客户当前问题，从 `客服经验库/知识库/` 中检索可复用的客服经验，辅助生成更自然、更像优秀客服的回复。

本技能只回答“怎么沟通”，不回答“事实是什么”。事实必须以 DClaw 企业智库为准。

## 使用时机

当客户问题属于以下场景时，可以使用本技能：

- 加盟费用、投资预算、选址、合同、政策、资料索取、售后等业务咨询。
- 客户有明显顾虑、异议、反问、试探、犹豫或情绪。
- 需要参考同事优秀话术、追问方式、风险提醒。
- 企业智库已经命中事实，但还需要更好的表达策略。
- 客户明确索取图片、文件、视频、音频、资料、链接、网盘等资源，尤其是工厂视频、产品视频、基地视频、门店视频、介绍视频等。

以下属于必须使用本技能的经验库强制参与场景：

- 品牌信任异议：客户说“没听过、不熟、靠谱吗、真的假的、小品牌、是不是杂牌、有什么实力”等。
- 资源索取：客户索要视频、图片、文件、音频、资料、链接、网盘、工厂视频、产品视频、基地视频、门店视频、介绍视频等。
- 价格、投入、合同、售后、保障、回本、亏损等顾虑或风险试探。
- 明显需要优秀客服话术承接的质疑、抱怨、犹豫、试探或情绪表达。

不适合使用本技能的情况：

- 只需查企业事实，且不需要话术策略。
- 问题涉及高风险事实但企业智库无资料；此时不能靠经验库编造结论，但仍可以使用经验库中明确存在的资源 URL 作为资料发送线索。
- 客户要求内部政策、隐私、其他客户信息。

## 检索流程

1. 先读取：

```text
客服经验库/知识库/index.md
```

2. 根据客户问题、意图、关键词和同义表达，定位 1-3 篇最相关经验页。
   - 品牌信任异议优先查“品牌知名度质疑应对”。
   - 资源索取优先查“视频资料索取与实力背书回应”或其他资料索取页。
3. 读取候选经验页。必要时沿 `See Also` 读取强相关页面。
4. 提取：
   - 适用场景
   - 客户真实意图
   - 沟通策略
   - 优秀回复示例
   - 禁止说法
   - 风险提醒
   - 可追问问题
   - 可发送资源链接
5. 返回给主回复流程时，只输出可用于生成回复的策略摘要，不要直接面向客户输出内部分析。

## 优先级规则

- DClaw 企业智库 = 事实依据。
- 客服经验库 = 表达策略、话术参考、追问建议。
- 当前会话记录 = 当前客户上下文。
- `human_reply_style` = 最终语气和真人感。

当企业智库和客服经验库都命中且不冲突：

- 以企业智库作为事实边界。
- 以客服经验库作为表达、追问和沟通策略参考。
- 最终回复不能超出企业智库允许的事实范围。

当客服经验库与企业智库冲突：

- 以企业智库为准。
- 不采用冲突经验。
- 必要时按经验库的风险提醒保守表达。

当只有客服经验库命中、企业智库未命中：

- 可以参考客户意图和沟通方式。
- 不得输出具体价格、政策、合同条款、承诺、加盟条件或售后结论。
- 对高风险问题只能给模糊方向、追问信息或说明需要确认。

## 资源链接规则

客服经验库可以提供资源发送策略和显式资源链接，但它不是企业事实来源。

- 显式资源链接优先级：客户索要资源时，企业智库没有明确资源链接，不等于“没有资料”；必须继续检索客服经验库。只有企业智库和客服经验库都没有明确 URL，才可以说暂时没有对应资料。
- 如果经验页中明确写了图片、文件、视频、音频、网盘或网页 URL，并且该资源适合当前客户意图，可以交给 `worktool_attachment_response` 整理为 `attachments`。
- 如果客户问“工厂视频”，优先匹配含有工厂视频的经验页；例如经验库中存在“工厂视频”URL 时，应作为 `video` 附件返回，而不是回复“没有视频资料”。
- 经验库中的资源不能覆盖企业智库事实；如果资源说明和企业智库冲突，以企业智库为准。
- 不要根据经验库话术编造资料链接、价格表、合同样例或视频地址。
- 如果只有“建议发招商资料”但没有明确 URL，只能在回复中说明可以稍后发送或需要确认，不能生成 `attachments`。
- 资源类型判断统一按 `worktool_attachment_response`：图片、文件、视频、音频可作为媒体附件；网页、网盘、表单等作为 `link`。

## 输出给主流程的格式

推荐内部摘要格式：

```text
客服经验库参考：
- 适用场景：
- 客户真实意图：
- 沟通策略：
- 可参考话术：
- 风险提醒：
- 建议追问：
- 可发送资源：
```

最终客户可见回复必须交给 `human_reply_style` 润色，并且不要提“我查了客服经验库”。
