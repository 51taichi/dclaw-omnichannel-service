# 群定时任务 @ 角色头像设计

## 目标

统一群定时任务弹窗中 @ 角色区域的视觉：移除标题和角色卡片里的线性人物图标，每个角色改用会话界面同款吉祥物头像。

## 展示规则

- “推送时 @ 群角色（可多选）”标题只显示文字，不再显示人物图标。
- 每张角色卡片不再渲染线性人物图标。
- 每张角色卡片统一使用 `./assets/ddeer.png`，与会话中的客户吉祥物头像保持一致。
- 头像使用固定尺寸、圆角和 `object-fit: cover`，不因角色姓名或身份文字长度改变尺寸。
- checkbox、角色姓名、身份说明及选中状态保持现有布局与交互。

## 实现边界

- 只修改群定时任务弹窗的 @ 角色区域。
- 不修改群角色基础配置、会话头像或其他人物图标。
- 不修改角色 ID、任务保存参数、@ 发送逻辑或服务端接口。

## 验证

- 自动测试约束标题不再包含人物 SVG。
- 自动测试约束每张角色卡片使用 `ddeer.png`，且旧线性人物图标不再渲染。
- 浏览器检查头像尺寸、文字对齐和多选 checkbox 布局。
- 运行相关测试及完整测试套件。
