# 群定时任务日期卡片选择设计

## 目标

优化群定时任务“每月执行日”选择器：保留 `1日` 至 `28日` 和 `月底` 的文本，移除可见 checkbox 方框，改为点击整张日期卡片切换多选状态。

## 交互与视觉

- 日期仍支持多选，点击整张卡片可选中或取消选中。
- 未选中卡片保持现有浅色背景、边框和文字层级。
- 选中卡片使用蓝色强调背景、蓝色边框和更醒目的文字颜色。
- 不显示 checkbox 方框，也不新增勾选图标，避免重复表达选中状态。
- `1日` 至 `28日`、`月底` 的显示文本保持不变。
- 三页月份选择、左右切换、键盘操作和响应式布局保持不变。

## 实现边界

- 保留原生 checkbox 作为表单值和无障碍语义来源，仅隐藏其视觉外观。
- 不修改 `monthlyDay` 字段名、日期值、保存接口或服务端调度逻辑。
- 不修改每周执行日选择器及其他表单 checkbox。

## 验证

- 自动测试约束月份日期卡片不再显示 checkbox 方框。
- 自动测试约束选中状态由整张卡片呈现。
- 运行群任务日期选择器相关测试及完整测试套件。
