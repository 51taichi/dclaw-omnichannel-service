# 群置顶与启用任务视觉状态设计

## 目标

- 让用户将常用群固定在群列表顶部，减少长列表中的重复查找。
- 让已启用的群任务具备明确但克制的运行状态，与“AI 正在和客户大大沟通中”的品牌视觉保持一致。

## 常用群置顶

- 每个群卡右上角增加纯图钉按钮，使用原生 `title` 和 `aria-label` 提示“置顶群聊”或“取消置顶”。
- 点击图钉只切换置顶状态，不触发群卡的选中或详情加载。
- 置顶数据保存在浏览器 `localStorage`，按工作区和 Bot 隔离；不修改服务端群数据与接口。
- 列表排序规则为：置顶群优先，置顶组和普通组内部都保持接口返回的原始顺序。
- 搜索、刷新、切换群详情后继续应用相同排序；不存在的群 ID 会在读取时忽略。

## 启用任务视觉状态

- 已启用任务卡增加双品牌色浅底、强调边框和低强度流动高光。
- 动画只作用于卡片背景或边缘，不改变尺寸、布局、按钮位置和文字可读性。
- 已停用任务继续使用当前降透明度的普通状态，不显示流动效果。
- 遵循 `prefers-reduced-motion`，用户关闭动态效果时退化为静态强调样式。

## 测试与验收

- 自动测试覆盖本地置顶键的隔离、排序稳定性、图钉交互边界和启用任务样式边界。
- 桌面与窄屏浏览器检查群名省略、日期标签、图钉按钮不重叠，任务卡动画不引起布局位移。
- 全量测试通过后只提交本次前端和测试文件，并推送到 `main`。
