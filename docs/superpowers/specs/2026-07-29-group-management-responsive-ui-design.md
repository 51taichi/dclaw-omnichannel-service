# 群管理响应式 UI 优化设计

日期：2026-07-29  
分支：`release/group-management-v1`

## 目标

在不改变群管理数据、接口和回复逻辑的前提下，复用任务 Tab 与推送 Tab 已有的交互和视觉模式，解决群背景占用空间、群角色横向溢出、联系人名单可读性差、群列表图标和布局不清晰，以及角色增多后页面被持续撑高的问题。

## 设计决策

### 群公告与群背景

- 创建群、修改群信息中的群公告，以及群配置中的群背景，统一沿用任务 Tab“通用规则”的 `expand-field-slot + expand-on-focus` 交互。
- 默认显示为紧凑单行输入区。
- 获得焦点时在固定槽位上方展开，方便编辑较长内容；失去焦点后恢复紧凑状态，展开过程不改变其他字段位置。
- 保存字段和接口保持为现有 `announcement` 与 `background`，不改变数据结构。

### 群管理图标

- 群管理 Tab、群列表、创建群弹窗等代表“群”的位置统一使用 `public/console/assets/group.png`。
- 会话 Tab 继续使用现有人物/会话图标，避免两个 Tab 视觉重复。
- 标签、编辑、保存等操作图标继续沿用 SVG 图标系统。

### 自适应高度与滚动

- 群管理内容区高度跟随可用视口，模式与任务 Tab 一致。
- 工作区本身不因群角色数量持续向下增长。
- 左侧群列表与右侧配置区各自支持纵向滚动。
- 右侧配置区的标题和配置内容保持同一滚动上下文，避免角色行覆盖页面浮动按钮。
- 小屏幕下恢复自然页面流，避免双滚动区域难以操作。

### 群角色

- 删除“角色由你维护，用于识别发言人与回复策略，不代表实时成员状态。”说明文本。
- 桌面端角色表格使用受容器约束的六列网格：成员名称、身份、职责与关系、回复策略、群成员备注、操作。
- 删除列使用固定紧凑宽度，前五列按内容重要性分配弹性空间。
- 群成员备注非空且与原备注不同时，保存角色会自动同步到 WorkTool；空值或未变化时不调用外部接口。
- 所有输入控件设置 `min-width: 0`，按钮不得越过右侧配置容器。
- 小屏幕下隐藏表头，角色行切换为带字段名称的纵向卡片。
- 新增角色与已有角色使用同一行结构，不增加独立布局分支。

### 创建外部群联系人

- 联系人选择复用推送 Tab 的卡片模式：头像、名称、右侧选中框、选中态底色。
- 列表桌面端固定为每行 4 列、每页 5 行（20 人），弹窗变窄时减少列数。
- 第五行下方使用与推送 Tab 一致的右对齐分页条，“每页 20”保持单行；搜索自动回到第 1 页，跨页选择保持不变。
- 联系人头像复用推送 Tab 的头像解析逻辑和资源。
- 点击整张卡片即可选中或取消，保留现有已选联系人状态。
- 数据源仍是创建群当前使用的私聊联系人接口，不新增轮询、不修改 WorkTool 行为。
- 创建群弹窗固定为“标题 / 可滚动内容 / 操作栏”三行，底部取消与创建按钮始终保留在独立操作栏中。

### 群列表

- 群列表头像改为 `group.png`。
- 单个群卡片按“头像 + 名称/备注 + 建立日期标签”组织。
- 建立日期使用群记录的 `groupCreatedAt`，按北京时间显示为系统日期标签；仅在群配置区保留回复方式，群列表不再显示“仅 @ 回复”等回复策略。
- 卡片内容强制占满可用宽度，并使用固定头像列、弹性文字列、固定日期列；名称与备注单行省略，任何文字长度都不能改变头像和日期标签的对齐位置。

## 不在本次范围

- 不调整群回复策略、标签规则、角色识别逻辑。
- 不修改创建群、修改群信息或成员备注的 WorkTool 接口调用。
- 不新增成员状态、轮询或群消息记录展示。
- 不抽象新的跨模块通用组件系统；只复用现有样式和必要的渲染结构。

## 验证

- 边界测试覆盖：独立群图标、固定槽位展开的群公告与群背景、受约束角色网格、联系人卡片复用、分页与操作栏布局、群建立日期标签和滚动容器。
- 运行群管理与控制台权限相关测试。
- 运行 JavaScript 语法检查与完整测试套件。
- 使用差异检查确认没有无关文件或接口改动。
