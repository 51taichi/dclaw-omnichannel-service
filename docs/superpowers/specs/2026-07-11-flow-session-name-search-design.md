# 客户会话名称搜索设计

## 目标

客户会话模块去掉开始日期和结束日期筛选，改为更常用的模糊搜索，便于按客户名或会话名快速定位会话。

## 范围

- 删除客户会话筛选区中的开始日期和结束日期输入框。
- 新增一个文本搜索框，文案为“搜索客户/会话”。
- 搜索范围包含 `receivedName`、`groupName`、`conversationKey`。
- 保留资产筛选、任务状态筛选、人工接手置顶和当前排序逻辑。
- 搜索在前端本地完成，不新增后端接口。

## 验收

- 页面不再出现 `flowSessionDateFrom` 和 `flowSessionDateTo`。
- 页面出现 `flowSessionSearchInput`。
- 输入客户名、群名或会话 key 片段时，会话列表按关键字过滤。
- 清空搜索框后恢复显示全部符合其他筛选条件的会话。
