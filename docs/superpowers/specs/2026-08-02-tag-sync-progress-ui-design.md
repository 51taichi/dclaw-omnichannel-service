# 企微标签同步进度交互设计

## 目标

- 从配置页移除可见的“Bot 绑定”模块，Bot 与 Agent 的维护继续由管理后台负责。
- “立即同步”启动后，按钮在真实同步任务结束前保持禁用，刷新图标持续旋转。
- 不再常驻展示可能过期的同步统计；任务结束后才在独立结果行展示本次观察到的最终状态。

## 交互

1. 页面加载只读取同步配置。若状态接口返回当前 Bot 有运行中的任务，则恢复按钮锁定并继续跟踪。
2. 管理员确认“立即同步”后，清空上一次页面结果，禁用按钮，将文案改为“同步中”。
3. 前端使用现有 `/api/bots/:botId/tag-sync/status` 接口每秒轮询，并只跟踪启动接口返回的 `run.id`。
4. `running` 和 `paused` 都视为进行中；只有 `completed`、`stopped`、`failed` 才结束跟踪。
5. 结束后恢复按钮，在表单下一整行展示待同步、处理中、失败、已同步以及完成状态和时间。
6. 切换 Bot、上锁或上下文失效时终止旧轮询，避免旧 Bot 的结果覆盖当前页面。
7. 单次轮询请求失败时继续下一轮；连续跟踪由当前 Bot 上下文控制，不改变后台任务。

## 兼容性

- 可见的 `botBindingPanel` 被移除。
- 现有脚本仍依赖 `botForm` 保存当前 Bot 的兼容字段，因此保留一个不可见、不可操作的状态表单，避免扩大重构范围。
- 服务端同步启动、暂停、恢复、重试和回调逻辑保持不变。

## 验证

- 边界测试验证配置页不再包含 `botBindingPanel`，但仍保留隐藏 `botForm`。
- 边界测试验证同步按钮具备忙碌状态、轮询、上下文取消和完成结果渲染。
- 运行控制台相关测试与全量测试。
