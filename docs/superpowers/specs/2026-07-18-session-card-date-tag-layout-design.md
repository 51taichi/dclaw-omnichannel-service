# 会话卡片日期标签布局设计

## 目标

将客户添加日期标签从会话卡片第二行移动到姓名右侧，减少卡片高度和空白，同时保证姓名、日期标签及人工接管开关稳定排列。

## 布局

- 会话侧栏宽度由 260px 增加到 310px，聊天记录区域使用剩余空间。
- 卡片首行按“头像、姓名、日期标签、接管开关”排列。
- 姓名使用固定宽度，超出后显示省略号，并通过 `title` 展示完整姓名。
- 日期标签只渲染 `tagType === "date"` 的标签；没有日期标签时不显示、不占位。
- 普通标签继续显示在卡片第二行，日期标签不再重复出现在第二行。
- 任务和资产图标保留在第二行右侧。

## 响应式边界

- 桌面宽度下侧栏为 310px。
- 小屏沿用现有单列响应式布局，不增加横向溢出。
- 日期标签允许收缩，但不挤压接管开关。

## 验证

- 前端边界测试验证日期标签与普通标签分开渲染。
- 验证姓名有固定宽度、省略号和完整名称提示。
- 验证侧栏宽度和首行网格结构。
- 运行完整测试集。
