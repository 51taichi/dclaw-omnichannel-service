# 客户首次发现日期标签设计

## 目标

客户添加日期不再依赖 WorkTool 新增好友事件。每个私聊会话首次进入控制台数据库时，以不可变的 `conversations.created_at` 作为首次发现时间，并按北京时间生成日期标签。

## 规则

- 仅私聊会话参与，群聊不打客户日期标签。
- 日期标签开关跟随 Agent 标签配置。
- 新会话在统一的会话入库边界自动补齐日期标签。
- 已有会话在开启或保存日期标签配置时，按其 `created_at` 批量回填。
- 清空会话只删除消息，不修改 `conversations.created_at`，因此不会改变日期标签。
- 同一会话只保留一个系统日期标签；历史错误日期会被首次发现日期替换。
- 标签日期使用 `Asia/Shanghai`，格式为 `yyyyMMdd`。

## 兼容性

WorkTool 好友事件仍可创建会话和激活任务，但不再是日期标签成功的必要条件。
