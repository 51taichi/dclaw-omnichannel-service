# 驾驶舱报告接收人三列布局设计

## 目标

将日报、周报、月报三个接收人字段从纵向三行改为桌面端一行三列，减少驾驶舱报告配置模块的垂直占用。

## 布局

- 三个接收人字段组成独立的接收人网格。
- 桌面端使用三个等宽列，按日报、周报、月报顺序从左到右排列。
- 每列继续使用当前 `图标 + 标签 + 文本域` 的组合样式。
- 三个文本域高度一致，内容较多时由文本域自身处理滚动或拉伸。
- 窄屏断点下切换为单列，避免标签和联系人内容被压缩。

## 行为边界

- 保留 `dailyRecipients`、`weeklyRecipients`、`monthlyRecipients` 字段名。
- 不修改表单提交事件、请求参数、API 或服务端保存逻辑。
- 不改变报告发送开关及底部操作按钮的功能。

## 验证

- 前端边界测试确认三个接收人字段位于三列网格中。
- 前端边界测试确认窄屏下网格回退为单列。
- 全量测试确认现有配置保存和其他控制台功能未受影响。
