# 群定时任务统一选择交互设计

## 目标

统一群定时任务弹窗中的多选交互，并优化任务启用开关的位置：每周日期、每月日期和 @ 群角色均使用整卡点击与一致的选中样式；“启用任务”开关移动到任务名称右侧。

## 日期与角色选择

- 每周执行日隐藏可见 checkbox，点击“周一”至“周日”的整张卡片切换多选。
- 每月执行日继续使用现有整卡多选样式。
- @ 群角色隐藏可见 checkbox，点击包含吉祥物头像、姓名和身份的整张卡片切换多选。
- 三类卡片统一使用蓝色背景、蓝色边框、蓝色文字和内描边表示选中。
- 原生 checkbox 保留为表单值和无障碍语义来源，仅隐藏其视觉方框。
- 键盘聚焦时，整张卡片显示清晰的焦点轮廓。

## 启用任务开关

- 文案保留“启用任务”。
- 使用现有 `switch-slider` 滑动开关组件，不显示原生 checkbox。
- 开关移动到任务名称字段右侧，两者处于同一行。
- 新建任务默认开启。
- 编辑任务时按照任务已有 `enabled` 状态显示开启或关闭。
- 窄屏仍保持任务名称在左、开关在右；名称输入区域可收缩，开关不可压缩或变形。

## 实现边界

- 不修改 `weeklyDay`、`monthlyDay`、`mentionRoleId` 或 `enabled` 字段名及值。
- 不修改任务校验、保存参数、接口或服务端调度逻辑。
- 不影响群角色头像、每月分页和其他页面的 checkbox、卡片或开关。

## 验证

- 自动测试约束三类卡片共享一致的选中和焦点样式。
- 自动测试约束每周与 @ 角色 checkbox 仅视觉隐藏，表单字段保持不变。
- 自动测试约束“启用任务”开关位于任务名称右侧、包含 `switch-slider` 且默认选中。
- 浏览器验证整卡点击、取消、多选、编辑状态及桌面和窄屏布局。
- 运行相关测试和完整测试套件。
